{% load i18n %} {% comment %} The confirmation ("please confirm your subscription") email. django-newsletter's own version of this is unstyled plain HTML; this one matches the newsletter's look — brand colour, the same Montserrat/Helvetica stack the MJML blocks use — so the first email a subscriber ever gets isn't the ugliest one. Hand-written email-safe HTML rather than MJML: it is a single centred card, and MJML would mean compiling on every signup for no visual gain. Tables, inline styles and no web fonts, because that is what mail clients agree on. Context is django-newsletter's (`newsletter`, `subscription`, `site`, `site_url`), plus `brand_color` and `from_name` added by prblm_mailer.sending.send_optin.
