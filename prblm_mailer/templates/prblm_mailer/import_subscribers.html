Upload a CSV from anywhere — Mailchimp, MailPoet, Brevo, a CRM, a spreadsheet. The columns don't have to be named anything in particular: the next screen shows which one it read as the email address, a few rows from your file, and exactly what the import would do, so you can correct it before anything is written.

Only the email address, name, groups and status are read. Groups look like Instrument: Guitar; City: Leeds — the format the export writes, so a file exported here re-imports unchanged.

Nothing is imported by this step, and no confirmation emails are ever sent by an import — mailing a freshly imported list in one go is the fastest way to get a sending domain blocked.
